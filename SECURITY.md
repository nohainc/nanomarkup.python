# Security policy

## Supported versions

The latest stable release receives security fixes. Older releases may be fixed
when the maintainers judge that practical.

## Reporting a vulnerability

Please use GitHub's **Report a vulnerability** form on this repository's
Security tab. Do not disclose a suspected vulnerability in a public issue.

Include the affected version, a minimal reproducer, the expected impact, and
any suggested mitigation. You should receive an acknowledgement within seven
days. A coordinated disclosure date will be agreed after the report is
validated.

For language-specification issues rather than Python implementation defects,
use the security policy in the Nano Markup specification repository.
